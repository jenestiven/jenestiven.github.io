Precision agriculture · 2026

Manuelita Smart

Ingenio Manuelita S.A., one of Colombia's largest sugarcane producers
  • A local-first desktop platform that centralizes the sugarcane productivity-mapping workflow in one place.
  • I built the FastAPI + Pydantic API over 9 sprints, with one unified lot data model shared by every workflow stage.
  • It pulls in data from Solinftec, Biosalc and NAX. I reverse-engineered the Biosalc TXT format and wrote a normalization algorithm for its productivity data.
  • I also built a QGIS/PyQGIS map pipeline alongside the ArcGIS/ArcPy one, using SAGA B-spline interpolation, Jenks classification and automated layouts.
  • Along the way I found the cartographic base was on Bogotá 1975 (EPSG:21896) instead of MAGNA-SIRGAS, and documented how that affects spatial accuracy.

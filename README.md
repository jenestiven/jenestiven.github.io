# Portafolio — Jhon González Aricapa

Un mapa (Mapbox GL JS) con tres lentes: **Topógrafo**, **Desarrollador GIS** y **Desarrollador de software**. Cada proyecto es una capa del mapa, y la vista **Read / Leer** muestra el mismo contenido como página. Inglés por defecto, con opción en español.

Stack: Astro 5, React 19, Mapbox GL JS 3, Tailwind 4.

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm build
```

Necesita `PUBLIC_MAPBOX_TOKEN` en `.env`.

## Dónde está el contenido

| Qué | Archivo |
|---|---|
| Perfil, estadísticas, herramientas, trayectoria, contacto | `src/content/profile/main.json` |
| Un proyecto por archivo | `src/content/projects/<id>.json` |
| Textos de la interfaz (EN y ES) | `src/lib/lab/i18n.ts` |
| Fotos, videos y demás archivos | `public/` (p. ej. `public/media/<id>/…`) |

Todo texto en inglés va en el campo principal. La versión en español va en el bloque `"es"` del mismo archivo; lo que falte ahí se muestra en inglés.

## Agregar un proyecto

Crea `src/content/projects/<id>.json`. Los campos obligatorios son `id`, `title`, `order`, `featured`, `lens` (`topography`, `gis` o `software`), `status` (`production`, `delivered` o `in-progress`), `tag`, `meta`, `summary`, `stack` y `layer` (la geometría ilustrativa del mapa). Usa uno de los proyectos existentes como plantilla.

- `"featured": false` lo manda a "Other projects".
- `"draft": true` lo oculta del mapa y de la página hasta que quieras publicarlo.

## Material audiovisual y enlace

Ambos son **opcionales**: un proyecto sin material no declara nada y no se muestra ningún espacio vacío. Se ven en el inspector del mapa y en la tarjeta de la vista Read.

### Carrusel de imágenes

Copia las imágenes a `public/media/<id>/` y declara:

```json
"media": {
  "type": "images",
  "images": [
    {
      "src": "/media/manuelita-smart/dashboard.webp",
      "alt": "Productivity map of the sugarcane lots",
      "caption": "Productivity map generated by the pipeline",
      "es": { "alt": "Mapa de productividad de los lotes", "caption": "Mapa de productividad generado por el pipeline" }
    },
    { "src": "/media/manuelita-smart/api.webp", "alt": "API documentation" }
  ]
}
```

`alt` es obligatorio (lo leen los lectores de pantalla); `caption` y `es` son opcionales. Con una sola imagen no aparecen flechas. Se recomiendan imágenes `.webp` de hasta ~1600 px de ancho.

### Video

```json
"media": {
  "type": "video",
  "src": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
  "title": "Manuelita Smart demo",
  "es": { "title": "Demo de Manuelita Smart" }
}
```

`src` puede ser un enlace de YouTube o Vimeo (se inserta el reproductor) o un archivo propio como `/media/<id>/demo.mp4`; en ese caso se puede añadir `"poster": "/media/<id>/portada.webp"`. Un proyecto tiene carrusel **o** video, no ambos.

### Enlace de redirección

```json
"link": {
  "url": "https://mi-proyecto.com",
  "label": "Live demo",
  "es": { "label": "Ver la demo" }
}
```

Sin `label`, el botón dice "Visit project" / "Ver proyecto". Se abre en otra pestaña. Puede ir junto con un carrusel o un video, o solo.
